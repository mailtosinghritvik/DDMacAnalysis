## 🛠️ Database Setup

### Step 1: Create the project_progress Table

The main requirement is to create the `project_progress` table in your Supabase database. 

**Option A: Using Supabase Dashboard (Recommended)**
1. Go to your Supabase dashboard
2. Navigate to **SQL Editor**
3. Run the following SQL script:

```sql
CREATE TABLE IF NOT EXISTS public.project_progress (
    id bigint generated by default as identity not null,
    project_id bigint null,
    jobcode_id bigint null,
    progress double precision null,
    created_at timestamp with time zone not null default now(),
    constraint project_progress_pkey primary key (id)
) TABLESPACE pg_default;

-- Add indexes for better performance
CREATE INDEX IF NOT EXISTS idx_project_progress_project_id ON public.project_progress(project_id);
CREATE INDEX IF NOT EXISTS idx_project_progress_jobcode_id ON public.project_progress(jobcode_id);
CREATE INDEX IF NOT EXISTS idx_project_progress_created_at ON public.project_progress(created_at);

-- Add check constraint to ensure progress is between 0 and 100
ALTER TABLE public.project_progress 
ADD CONSTRAINT chk_progress_range CHECK (progress >= 0 AND progress <= 100);
```

**Option B: Using the provided SQL file**
```bash
# Run the SQL file directly
psql -d your_database -f create_simple_project_progress_table.sql
```

### Step 2: Verify Table Creation

Run the test script to verify everything is working:
```bash
python test_foreman_analysis.py
```

## 🔧 Troubleshooting

### Common Issues

#### 1. Table Not Found Error
**Error**: `Could not find the table 'public.project_progress'`
**Solution**: Create the table using the SQL script provided above

#### 2. Permission Denied
**Error**: `Permission denied` or `403 Forbidden`
**Solution**: Check your Supabase API key and permissions

#### 3. No Data Displayed
**Error**: Empty tables or "No data available"
**Solution**: The system will show sample data if real tables are empty

Enable debug information by checking the "Show Raw Data Debug" option in the interface.
