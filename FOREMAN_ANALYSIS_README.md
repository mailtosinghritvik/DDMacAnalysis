# Foreman Analysis Dashboard

## Overview
The Foreman Analysis Dashboard is a comprehensive project management tool designed for construction foremen to track and manage project progress, task completion, and jobcode status. This system provides real-time progress tracking with visual analytics and intuitive controls.

## Features

### 🏗️ Project Progress Tracking
- **Real-time Progress Updates**: Update progress percentages (0-100%) for both tasks and jobcodes
- **Visual Progress Charts**: Interactive charts showing progress distribution and trends
- **Progress Analytics**: Comprehensive analytics with statistics and insights

### 📋 Task Management
- **Task Selection**: Easy dropdown selection of available tasks
- **Progress Sliders**: Intuitive slider controls for setting progress percentages
- **Real-time Updates**: Instant progress updates with database persistence

### 🏷️ Jobcode Management
- **Jobcode Selection**: Dropdown selection of available jobcodes
- **Progress Tracking**: Track progress for specific jobcodes
- **Status Monitoring**: Monitor completion status across different jobcodes

### 📊 Analytics Dashboard
- **Progress Overview**: Visual representation of all project progress
- **Statistics**: Average, maximum, and minimum progress metrics
- **Distribution Charts**: Pie charts showing progress distribution across ranges
- **Trend Analysis**: Historical progress tracking and trends

## Database Schema

### project_progress Table
```sql
CREATE TABLE public.project_progress (
    id bigint generated by default as identity not null,
    project_id bigint null,
    jobcode_id bigint null,
    progress double precision null,
    created_at timestamp with time zone not null default now(),
    constraint project_progess_pkey primary key (id),
    constraint project_progess_jobcode_id_fkey foreign KEY (jobcode_id) references jobcodes (id),
    constraint project_progess_project_id_fkey foreign KEY (project_id) references projects (id)
) TABLESPACE pg_default;
```

### Key Features
- **Progress Validation**: Progress values are constrained between 0 and 100
- **Foreign Key Relationships**: Links to projects and jobcodes tables
- **Timestamp Tracking**: Automatic creation timestamp for audit trails
- **Indexed Performance**: Optimized indexes for fast queries

## Usage Guide

### Accessing the Dashboard
1. Navigate to the main DDMac Analytics Dashboard
2. Click on "👷 Foreman Analysis" in the navigation section
3. The Foreman Analysis page will load with all available data

### Updating Task Progress
1. Go to the "📋 Task Management" tab
2. Select a task from the dropdown
3. Use the slider to set progress percentage (0-100%)
4. Click "Update Task Progress" to save changes

### Updating Jobcode Progress
1. Go to the "🏗️ Jobcode Progress" tab
2. Select a jobcode from the dropdown
3. Use the slider to set progress percentage (0-100%)
4. Click "Update Jobcode Progress" to save changes

### Viewing Analytics
1. Go to the "📈 Progress Analytics" tab
2. View progress charts and statistics
3. Analyze progress distribution across different ranges
4. Monitor overall project health
